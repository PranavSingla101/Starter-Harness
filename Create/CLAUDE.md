# CLAUDE.md — Starter Harness

## ⚠️ This Repo Is a Scaffold, Not an App

There is no application code here. `Docs/` holds blank templates. This folder is the mold, not the cast.

---

## Mandatory Reading Order

Before filling in any doc, read these files **in order**:

1. `Docs/Project-overview.md` — what the product is, who it's for, scope
2. `Docs/Architecture.md` — stack decisions (frontend, backend, DB, hosting)
3. `Docs/Roadmap.md` — what's in v1 vs later
4. `Docs/UI-context.md` — what the UI should do
5. `Docs/UI-feature-detail.md` — buttons/elements documented for consistency
6. `Docs/Feature-specs/` — one file per feature spec
7. `Docs/Screenshots/` — reference mockups, linked from the docs above
8. `Docs/Progress-tracker.md` — current phase, what's done, what's next
9. `Docs/Startup.md` — how to run/set up the project locally

**After every meaningful change**, update `Docs/Progress-tracker.md`.
**If your change affects scope or architecture**, update the relevant `Docs/` file before continuing.
